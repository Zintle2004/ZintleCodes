# Project-1.0 — Bootstrap scaffold

This branch (feature/bootstrap-scaffold) contains a single-page Bootstrap 5 scaffold personalized for Zintle Ngculu.

Files:
- index.html — single-page site (Bootstrap 5 CDN + Google Fonts)
- assets/styles.css — theme and custom styles (dark: black + navy)
- assets/script.js — small JS for smooth scrolling and dynamic year

How to use
1. Add your CV to `assets/CV-ZintleNgculu.pdf`.
2. Update any placeholders in `index.html` (location, LinkedIn URL, project links).
3. Test locally: open `index.html` in a browser.
4. Deploy: push to GitHub and enable Pages or use Vercel/Netlify (static site).
